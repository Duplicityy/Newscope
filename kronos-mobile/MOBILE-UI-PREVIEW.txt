In-game Menu > Edit layout:
- Drag individual tab buttons, all five hotkeys, menu/chat/keyboard/collapse/logout controls, minimap and chat panel.
- Panel chooser selects a real client panel; each tab remembers its own panel position.
- Select a button, then Size / opacity. Size: 60-180%; opacity: 10-100%.
- Save persists on this device. Cancel restores the starting positions and styles. Reset restores defaults, which can then be saved or cancelled.
- Edit outlines remain visible for faint buttons. All edit touches are consumed; no world mouse events are sent. A second finger cancels the drag.
- Positions use relative available travel and clamp within the safe game canvas across screen sizes. Rendering and touch geometry share MobileGeometry.
- Buttons can deliberately overlap; the editor selects the smallest target at the touch point. Move it aside to reach another underneath.

From the parent Windows workspace:
  ./Build-Kronos-Mobile.ps1 -StageOnly
  ./Test-Kronos-Mobile.ps1 -Cacio -RegistrationTest -MobileUiTest

For Android compile/lint only, set JAVA_HOME to the bundled tools/jdk21 JDK, ANDROID_HOME to tools/android-sdk, ANDROID_USER_HOME to tools/android-user, GRADLE_USER_HOME to .gradle-home-mobile, then from android:
  ./gradlew.bat :kronos:compileDebugJavaWithJavac :kronos:externalNativeBuildDebug :kronos:lintDebug --no-daemon --max-workers=2

After preview review, the full workspace command ./Build-Kronos-Mobile.ps1 creates and copies the APK to ../mobile-release/Kronos-Mobile.apk. It was run after the user reviewed the preview and requested packaging.
