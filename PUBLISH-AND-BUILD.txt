NEWSCOPE COMPLETE SOURCE SNAPSHOT

Layout
  kronos-osrs-184/Kronos-master: server/updater/client, matching Cache/data
  kronos-osrs-184/content-tools: current cache/asset import tools
  kronos-mobile: Android/iOS/RuneMobile sources and final mobile bridge/chat code
  windows-client: Windows support overlay and smoke tooling
  tools: build/setup scripts and retained test/import helpers
  vendor/maven: exact resolved public legacy Java artifacts, POMs and notices
  assets-payload: reversible binary/large-data transport and checksum manifest

No original Git worktree, private server state, credentials or signing key is
included. Source includes current uncommitted integration changes. Copies of
private integration-token literals are redacted. LoginDecoder reads the server
private exponent through the kronos.rsa.privateExponent JVM property instead of
embedding it in published source. This does not modify production's original key.

RESTORATION
Python3.10+:
  python tools/content242/restore_assets.py
This restores all required Cache/data, images, wrapper JARs, Maven dependencies
and pinned Android runtime inputs. It checks chunk/archive/file hashes and skips
identical existing files; altered local assets are not overwritten by default.

PREREQUISITES
Windows x64; PowerShell7; JDK8 at tools/jdk8/<distribution>/; JDK21 at
tools/jdk21/<distribution>/. tools/downloads contains public JDK metadata; the
existing tools/install-toolchain.ps1 can install JDK8. Java8 builds Gradle6.4.1
server/client; Android uses Java21 and Gradle8.8. Gradle wrappers download their
distributions from services.gradle.org. Use a short clone path on Windows.

Android requires SDK API35, NDK27.0.12077973 and CMake3.22.1 under tools/android-sdk.
Install with Google's sdkmanager using JDK21. Android's current AGP8.6 dependencies
resolve from Google's repository/Maven Central; SDK/JDK/Gradle installations and
the Android dependency cache are not copied. The exact bionic ARM64 JRE21 archive
and Cacio1.18 inputs ARE retained under tools/downloads because the historical
moving release URL can return different bytes. The builder checks their hashes
and includes runtime legal notices. See vendor/README.md and RuneMobile notices.

BUILD
  pwsh ./Build-Source.ps1 -Project all
  pwsh ./Build-Kronos-Mobile.ps1
  pwsh ./Build-Kronos-Windows.ps1
Build-Source uses the restored vendor/maven first. -Offline is optional after
the Gradle distribution is installed. The default desktop build uses already
injected standalone client sources; historical deobfuscation/development tools
remain in source but are not enabled by default because old upstream artifacts
are unavailable. Gradle source/build warnings are not removed by this export.

The mobile clone builder is derived from the final deployed builder, including
native chat traversal hooks. Only original-machine snapshot/branch guards are
replaced with clone-local paths; source checks in the deployed workflow remain
unchanged. AppID local.kronos.mobile, version0.4.0/code9 and existing UI/preferences
remain in source. Keep the existing private signing identity in a protected
ANDROID_USER_HOME for upgrades. No private keystore is included.

RUN A SEPARATE CLONE
If you do not have the existing matching private RSA key, run
  pwsh ./New-Local-Rsa.ps1
BEFORE building. This generates a new clone-local pair, stores the private
exponent only in ignored local-runtime/rsa-private-exponent.txt, and replaces the
matching public modulus in server and desktop Client source. Rebuild server,
desktop and mobile so all clients use that pair. The helper refuses existing
key files and never prints the exponent. This is for a separate deployment;
it does not create clients compatible with the original production RSA pair.
Use server.properties.example and Start-Kronos.ps1. Provide matching private RSA
configuration privately as its launcher documents. The launcher uses a separate
local-runtime registry/player directory, defaults to loopback, requires a 4GB
game heap plus512MB updater and checks memory. It refuses occupied ports rather
than replacing another server. New registrations are ordinary accounts.
Never copy production player files or keys into Git.

DEPLOYMENT / AUDIT TOOLING
Use nested kronos-osrs-184/Kronos-master/tools/content242 for full-release tools;
their relative paths resolve to kronos-osrs-184/content-tools. Root tools copies
also retain historical development harnesses, which may require explicit paths.
Local sealed bundles, original account grants, snapshots and rollback receipts
are intentionally not published. A different machine/build must collect and
seal its own evidence. Hollow Depths attestation files in this copy are disabled
and must be freshly audited; do not interpret old machine hashes as approval.

Public map region keys are game cache content; they are unrelated to account or
signing secrets and remain with matching content. Generated test fixtures are
excluded and can be regenerated by their included source tooling. The public
cache and all runtime metadata are included without regeneration.
