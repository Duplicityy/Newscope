# Automation changelog

## Expanded candidate

- Added a serial scheduler and progression queue with one bounded second pass after measured XP.
- Integrated the first native drivers for all 23 standard skills. Expanded from Mining to local gathering, recipe production, inventory-funded support skills, combat styles, Slayer, Hunter, Farming and Construction.
- Added original Thermonuclear Smoke Devil, Vorkath and Zulrah controllers. Vorkath and Zulrah report observed native hazards and encounter state through explicit, narrow hooks. iDungeon, ToA and ToB retain their existing behavior.
- Added a signed Android portrait panel with one-tap entry from the existing Android menu. Uses the current game account and existing network session. Windows retains the native panel.
- Expanded exact fixture checks across native actions, guarded production, routing, conservation and boss decisions.

## Original Mining milestone

Added exact-owner access, native event ownership, preferences for the current login, Mining and banking, and the server and 21-repository audits. No third-party code was imported.
