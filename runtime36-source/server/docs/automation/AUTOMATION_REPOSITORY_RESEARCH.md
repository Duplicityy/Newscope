### Selection

- Mining is a good opening slice because a native Mining action already exists. Rank methods by legal tools, level, rock availability and bounded reachability. Make progression, full inventory, unavailable resources and blocked paths visible in status.
- Implement skill production next by reusing canonical recipes and item constraints. A plan should report ingredient shortages before it starts, then verify the exact inventory/XP outcome of each batch.
- Apply compact, single-action priority dispatch inside a session. Keep task data per owner and derive progress from game ticks and server state.
- Add Kraken or a limited Slayer task loop only after verifying native travel, task/instancing requirements, combat phases, loot, recovery and exit. A live-game bot file does not establish Newscape compatibility.
