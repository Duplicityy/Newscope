# World source review

The review used GitHub repository metadata, complete source trees and selected pinned implementation files. The installed Newscape cache, source and authored gameplay data determine which IDs and actions can be used in the development build. This work used external references to check implementation patterns and to screen published map metadata.

## Quests and activities

The [quest source audit](QUESTS.md#research) links to server persistence, journal, requirements and reward implementations in TSPS, OpenRune, Lost City and 2009Scape. It also covers what Quest Helper observes from its client. River Watch uses Newscape's own player saves, object actions, dialogue and inventory. It can be completed with the installed client protocol.

## Confirmed Newscape outcomes

- The calf and shop repairs use existing Newscape records and cache definitions. [NPC and shop verification](PVE_REPAIR.md)
- The native region survey found all 55 authored transport origins. Forty-three have the expected action slot. The other 12 use actionless definitions at the recorded positions, even though their proposed destinations clear the floor check. This includes seven squeeze-throughs, two entrances and three exits. Interactions need a verified visible client action and scope before enabling these links.
- Public OpenRS2 metadata matches the installed containers for all 19 unresolved scenery archives. The extra key catalogue produced no matching decode. [Landscape evidence](LANDSCAPE_RESEARCH.md)
