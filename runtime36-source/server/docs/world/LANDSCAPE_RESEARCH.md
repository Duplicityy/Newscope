# Remaining landscape dependencies

The isolated development build retains 13 verified repairs out of the 32 initially blocked installed landscapes. Nineteen installed scenery archives still require matching keys or owner-supplied, compatible scenery. One reference square, `16457`, is absent. The cache audit and this follow-up ran offline against development inputs. [Coverage baseline](COVERAGE.md)

## Absent reference square

The pinned revision 242 reference contains square `16457` at `(64,73)`. The existing tile decoder consumes 80,426 bytes for its four planes, followed by 9,564 unhandled terrain bytes. The reference scenery stream contains 6,251 placements. The available map tooling establishes the normal terrain layout but leaves the trailing records uninterpreted. Porting that square requires an owner-supplied compatible terrain and scenery pair, including verified handling for those records. [Pinned cache 2757](https://archive.openrs2.org/caches/runescape/2757), [Newscape terrain converter](../../content-tools/modern_definitions.py), [Pinned RuneLite map loader](https://github.com/runelite/runelite/blob/41f2c2838f4a49cc8e4bd383b3a4bff1a772ee53/cache/src/main/java/net/runelite/cache/definitions/loaders/MapLoader.java)

## GitHub references for follow-up checks

- **Shortest Path** records directed origin and destination tiles with quest, item, skill, and player-variable gates. Its route files can identify a travel edge to check. Validate each direction independently in Newscape using the installed endpoint, plane, interaction, state restrictions, and fees. Route availability in a client planner covers a different check from the server accepting and completing the interaction. [Pinned transport format](https://github.com/Skretzo/shortest-path/blob/a7dd4a27f7909b30ea710a6d4a2d5b6706a13865/docs/Transport-TSV-format.md), [BSD 2-Clause license](https://github.com/Skretzo/shortest-path/blob/a7dd4a27f7909b30ea710a6d4a2d5b6706a13865/LICENSE), [Newscape travel code](../../Kronos-master/kronos-server/src/main/java/io/ruin/content/content242/WorldTravel242.java)
- **Shortest Path tooling** distinguishes projected walkability from the existence of an interaction anchor. Its collision dumper combines terrain flags, object types, and bridge planes. The anchor drift test checks placement, menu actions and transformed definitions separately. Use those checks as a validation pattern for repaired Newscape squares, then test dynamic doors, plane changes, and arrival tiles with the native region and movement code. The tooling repository lists no repository-level license. [Pinned collision dumper](https://github.com/osrs-pathfinding/shortest-path-tooling/blob/f9e8722b8db03465eff4041602f887fc62cc617e/collision-map-update/CollisionMapDumper.java), [Pinned anchor test](https://github.com/osrs-pathfinding/shortest-path-tooling/blob/f9e8722b8db03465eff4041602f887fc62cc617e/src/test/java/shortestpath/dump/TransportAnchorDriftTest.java), [Newscape region loader](../../Kronos-master/kronos-server/src/main/java/io/ruin/model/map/Region.java)
- **OpenRS2** associates a candidate key with a specific compressed container after a successful decode and records the decompressed size and CRC. That provides archive-level evidence. A Newscape repair additionally needs a complete scenery stream and all referenced installed object definitions, followed by native initialization. [Pinned key validator](https://github.com/openrs2/openrs2/blob/50175bc519947775938405f6288be15fe70b7363/archive/src/main/kotlin/org/openrs2/archive/key/KeyBruteForcer.kt), [ISC license](https://github.com/openrs2/openrs2/blob/50175bc519947775938405f6288be15fe70b7363/LICENSE)
- **OpenRune FileStore and Displee** provide independent format checks. OpenRune's legacy map rewrite reads the matching key and skips that workflow from revision 237 onward. The 19 archives originate in the older layout, so the revision 242 reference does not supply keys for them just by sharing a map coordinate. Displee's index code confirms that group CRC and Whirlpool exclude disk revision bytes. No dependency changes or alternate cache writes were required. [Pinned OpenRune map task](https://github.com/OpenRune/OpenRune-FileStore/blob/1ba745b66c20a1d549076613f761427249842c30/tools/src/main/kotlin/dev/openrune/cache/tools/tasks/impl/RemoveXteas.kt), [Pinned Displee index](https://github.com/Displee/rs-cache-library/blob/20c67f507e7acd7db7371e1d329314d5ea9ad536/src/main/kotlin/com/displee/cache/index/Index.kt), [Displee MIT license](https://github.com/Displee/rs-cache-library/blob/20c67f507e7acd7db7371e1d329314d5ea9ad536/LICENSE)

## Reproduce the catalogue check

Save a published OpenRS2 catalogue locally and rerun the existing resolver with `--key-catalogue`. The optional catalogue contributes keys after existing square-specific candidates. Each positive result must pass the installed archive CRC, container decode, complete scenery stream, tile bounds, and object-definition checks. The report fingerprints the catalogue and records the source of any catalogue-only match. The registry remains a separate reviewed input to the development build.
