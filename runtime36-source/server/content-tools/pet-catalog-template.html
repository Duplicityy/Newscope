Newscape Pet Catalog

Browse NPC pets and existing pets. Search by name or ID to see the drop rate, follower size, and available forms.

NPC pets use a separate roll after an eligible kill. Existing pets retain their own rules. A listed base roll excludes progression guarantees and activity-specific modifiers. An activity source may set its own rate.

Each image is a capture of an existing cache model. Previews fit their cards, so use the listed scale for in-game size. Where a model could not be captured, the card shows the pet’s existing inventory model and labels it.
