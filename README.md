# Newscape

The current owner release is **Runtime 36 / Expedition v46**. The private Ubuntu server is running the matching server update.

| Platform | Download | Installation |
| --- | --- | --- |
| Windows x64 | [Expedition v46 standalone EXE](https://github.com/Duplicityy/Newscope/releases/download/runtime36-expedition-v46/Newscape-Windows-Expedition-v46.exe) | Run the 302 MB executable. Java and the full game cache are included. |
| Android | [Expedition v46 APK](https://github.com/Duplicityy/Newscope/releases/download/runtime36-expedition-v46/Newscape-Mobile-Ultra-Expedition-v46.apk) | Install the signed APK over the existing owner app to retain its settings. |

The [Windows update ZIP](https://github.com/Duplicityy/Newscope/releases/download/runtime36-expedition-v46/Newscape-Windows-Expedition-v46.zip) is also available for existing [Newscape Launcher](windows-launcher/README.md) installations.

The Windows and Android clients use the same accounts, cache handshake, and world. The release adds the Daemonheim Expedition Ledger, updated teleport destinations, NPC dialogue and animation fixes, repaired doors and floor transitions, fairy-ring fixes, passenger journeys, and 48 charter sailings across eight eligible ports.
